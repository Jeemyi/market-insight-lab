# MARKET INSIGHT LAB v2 — 실제 숫자가 먼저인 금융시장 읽기

2026-11-09 업데이트. 기존 **학습 프레임 카드**를 첫 화면에서 없애고, 날짜가 일치하는 **실제 관측 수치**가 있어야만 분석 카드를 만들도록 바꿨습니다.

## 바로 실행하기 (Windows)

1. ZIP 파일을 압축 해제합니다. `build.py`, `metrics.py`, `requirements.txt`, `site` 폴더가 보이는 **안쪽 `market-insight-lab` 폴더**를 엽니다.
2. 파일 탐색기 주소창(오른쪽 검색칸 아님)을 클릭해 `cmd`를 입력하고 Enter를 누릅니다.
3. 검은 창에 아래를 차례대로 입력합니다.

```cmd
python -m pip install -r requirements.txt
python build.py
```

4. `site` 폴더 안의 `index.html`을 더블클릭합니다.
5. 로컬 사용 시 **매일 `python build.py`를 다시 실행해야** 최신 데이터로 바뀝니다. HTML 파일을 다시 여는 것만으로는 갱신되지 않습니다.

### 미리보기와 실제 기사 구분

ZIP 안의 최초 `site/index.html`은 화면 예시입니다. 상단에는 **2026-11-06의 실제 코스피 급락 사례**를 역사적 사례로 보여주고, 하단 기사 목록은 **가상 학습용 샘플**입니다. `python build.py`가 성공하면 과거 사례와 가상 기사들이 실제 수집 데이터로 교체됩니다.

## 카드가 어떻게 만들어지나

이 버전이 자동으로 다루는 데이터 연결은 다음과 같습니다.

- **국채 금리차:** 미국 국채 10년물(DGS10)과 2년물(DGS2)의 같은 날짜 금리차 및 5개 공통 관측구간 변화(bp)
- **환율과 위험선호:** 달러/원(DEXKOUS)과 VIX의 같은 날짜 변화폭(%와 포인트)
- **주가와 신용위험:** S&P 500과 미국 하이일드 회사채 옵션조정 스프레드(BAMLH0A0HYM2)의 동행 또는 엇갈림
- **주가와 변동성:** S&P 500과 VIX의 같은 날짜 변화

각 카드의 구조: **제목(실제 변화폭) → 근거 숫자 → 무엇이 함께 움직였나 → 가능한 해석 → 다른 해석 → 추가 검증할 지표 → 원자료/FRED 링크 → 관련 RSS 기사**.

이 자료들은 미국 시장과 환율에 대한 관측입니다. **한국 코스피 종목별 시총 비중 및 지수 기여도를 직접 산출하는 기능은 아직 없습니다.** 해당 숫자를 임의로 추정하지 않습니다.

## 뉴스와 지표의 구분

- RSS: 한국경제, 매일경제, 한국은행 경제·증권·국제/정책 등 9개 피드를 시도합니다. 최근 7일 이내 기사를 고르고 관련 주제에 연결합니다. 일부 RSS 소개문은 짧거나 빈 내용일 수 있습니다.
- 수치: 미국 세인트루이스 연방준비은행 **FRED의 다운로드 CSV**를 읽습니다. FRED 코드와 관측 날짜, 비교 기간을 화면에 명시합니다. CSV 다운로드 주소는 공개 제공 기능이지만, 장기적으로 URL이 변경될 수 있습니다.
- **관련 기사 목록은 배경을 읽도록 돕는 자료**이지, 자동으로 작성한 인과적 설명을 증명하는 자료가 아닙니다. 같은 방향의 지표가 있다고 해서 원인 관계가 확정되지는 않습니다.
- 한 지표가 지연·미공개되거나 날짜가 서로 맞지 않으면 자동으로 분석을 보류합니다. 임의로 숫자를 채우지 않습니다.
- 기사 전문과 유료 정보를 우회 수집하지 않습니다. 공개 RSS 설명 및 짧은 공개 발췌만 사용합니다.

## 중요한 품질 한계

이 버전은 **수치 기반 연결을 자동으로 보여주는 기초형**입니다. 매일 독창적인 분석 칼럼을 편집자가 쓴 것처럼 생성하는 기능은 아닙니다. 이를 위해서는 더 많은 한국 증시 공식 시계열(종목별 비중, 상승·하락 종목 수, 투자자별 수급), 안정적인 기사 전문 이용권한, 엄격한 출처 확인, 별도의 AI 분석/검수가 필요합니다. 특히 '삼성전자와 SK하이닉스가 코스피 하락의 70%에 기여' 같은 문장은 정확한 기준일·지수 구성·기여도 산식이 없으면 보여주지 않습니다.

현재 v2의 기본 실행에는 **OpenAI API 키가 필요 없으며 과금도 없습니다.** (기존 실험용 AI 코드와 무관한 독립 실행 버전입니다.)

## 매일 자동 갱신: GitHub Pages (선택)

1. GitHub에서 무료 계정을 만듭니다.
2. **Public** 저장소를 만들고 이 프로젝트 안의 파일 전체(숨김 `.github` 폴더 포함)를 올립니다.
3. `Settings → Pages → Source: GitHub Actions`를 선택합니다.
4. `Actions → Daily MARKET INSIGHT LAB → Run workflow`로 최초 실행합니다.
5. Pages에서 발급된 웹 주소를 즐겨찾기합니다.

설정된 예약 실행은 한국 시간 약 07:17 / 12:17 / 18:17입니다. GitHub Actions는 실제 실행이 지연되거나 건너뛰어질 수 있습니다. 자동 배포가 완료된 뒤 웹사이트를 새로고침하면 갱신된 기사와 FRED 자료를 볼 수 있습니다. **푸시 알림은 없습니다.**
